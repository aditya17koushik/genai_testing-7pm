# Frequently Asked Questions (FAQ)

## Q1. How do I check if Python is installed?

Open **Command Prompt** and run:

```bash
python --version
```

or

```bash
py --version
```

Expected Output:

```text
Python 3.x.x
```

---

## Q2. How do I check if pip is installed?

Run:

```bash
pip --version
```

Expected Output:

```text
pip xx.x.x
```

---

## Q3. VS Code is showing "Select Python Interpreter". What should I do?

1. Press **Ctrl + Shift + P**
2. Search for:

```text
Python: Select Interpreter
```

3. Select the installed Python version.

Alternatively,

Click the Python version displayed at the **bottom-right corner** of VS Code and select the appropriate interpreter.

---

## Q4. I installed Python, but the `python` command is not working.

Possible reasons:

* Python was not added to PATH.
* Command Prompt was opened before installation.
* VS Code needs to be restarted.

### Solution

* Restart Command Prompt or VS Code.
* Run:

```bash
py --version
```

If this works, Python is installed successfully.

If neither command works, reinstall Python and ensure that **"Add Python to PATH"** is checked during installation.

---

## Q5. I cannot see the ▶ Run button in VS Code.

Ensure that:

* The file has a **.py** extension.
* The Microsoft Python Extension is installed.
* A Python Interpreter has been selected.
* Restart VS Code if necessary.

# First Python Program

Create a file named:

```text
hello.py
```

Write the following code:

```python
print("Hello, World!")
print("Welcome to Python Programming!")
```

Run the program using one of the following methods:

* Click the **▶ Run** button in VS Code.
* Right-click inside the editor and select **Run Python File in Terminal**.
* Open the integrated terminal (`Ctrl + ``) and run:

```bash
python hello.py
```

or

```bash
py hello.py
```

Expected Output:

```text
Hello, World!
Welcome to Python Programming!
```
